Abstract

Chunking is a hidden bottleneck in dense retrieval and retrieval-augmented generation: it determines the units that can be indexed, retrieved, and used as evidence. Yet most systems segment documents with fixed token windows or globally thresholded similarity drops. We propose Seismos, which models consecutive sentence-embedding similarities as a document-level signal and derives boundary decisions from the null hypothesis of no semantic transition.

Across BEIR corpora we find three corpus-invariant properties: bimodal document structure, rapid survival decay of shallow minima, and positive lag-1 autocorrelation. Accounting for them yields a normalized discrete Laplacian detector with a single interpretable decision rule. Under one fixed configuration, Seismos improves over fixed-length, recursive and production semantic chunkers on five BEIR benchmarks, transfers unchanged to held-out TREC-COVID, stays competitive on long-document and multilingual retrieval, and in end-to-end RAG retrieves better evidence and yields more faithful answers at 15–23× lower preprocessing cost.

Method

Chunking as hypothesis testing

Under the null of no topic shift, the document mean cancels out. The right normalizer is the signal's own variability.

Step 1 · Null

The mean cancels

With no boundary at \(i\), the slope into a valley has zero mean, so \(\bar{x}_D\)-scaled thresholds are misspecified.

\[ \operatorname{Var}(x_{i-1}-x_i)=2\sigma^2 \]
Step 2 · Autocorrelation

Similarities are AR(1)

Lag-1 ACF is 0.27–0.38 on every corpus. The second difference has an exact AR(1) variance.

\[ \operatorname{Var}(D_i)=\sigma^2(6-8\rho+2\rho^2) \]
Step 3 · Detector

One self-normalized test

\(\hat{s}_D=\operatorname{std}(D)\) absorbs both \(\sigma\) and \(\rho\). Split where

\[ t_i=\frac{x_{i+1}-2x_i+x_{i-1}}{\hat{s}_D}>k \]
The whole detector in NumPy sketch of Algorithm 2 
def seismos_chunk(sentences, encode, k=2.5):
    n = len(sentences)
    if n < 5:
        return [" ".join(sentences)]
    E = encode(sentences)                         # (n, d), L2-normalized
    x = np.sum(E[:-1] * E[1:], axis=1)           # x_i = <e_i, e_i+1>
    D = x[2:] - 2 * x[1:-1] + x[:-2]              # discrete Laplacian
    s = D.std()                                   # absorbs sigma and rho
    B = set() if s == 0 else set(np.flatnonzero(D / s > k) + 1)

    chunks, cur = [], [sentences[0]]
    for i in range(n - 1):                       # boundary i sits between s_i and s_i+1
        if i in B:
            chunks.append(" ".join(cur)); cur = [sentences[i + 1]]
        else:
            cur.append(sentences[i + 1])
    chunks.append(" ".join(cur))
    return chunks
